# TeleVecha message gallery

Register the gallery in the local DerpDesign catalog with `node demos/derpdesign/register.mjs`. It appears under **TeleVecha · Design → Mission notebook · messages and media**. Passing an isolated DerpDesign session file registers and selects it in that session.

The gallery uses the production HTML entry, styles and animations. The scenario harness drives the mounted app. The sample chats share the application's conversation renderer and fixture transport. Mission notebook covers message cards, stickers and players. Camera tests includes small, square, portrait, panoramic and landscape originals. Contact sheets includes mixed media, document albums, and groups of two, three, five and ten. The Aspect ratios chat compares narrow portraits either side of the crop threshold, a vertical strip, a wide photograph and panoramas up to 16:1. Open any photo or movie to compare its tile with the original. Dedicated panes open the attachment chooser, chat actions, main menu and appearance settings. The document pane centers a file next to a voice message. In **Message arrivals**, send a message through the composer to receive a flight update. **Emoji, GIFs and stickers** opens the expression picker for switching tabs and packs. Each pane starts with its own in-memory history.

The local photos and short animated crops are derived from the public-domain NASA portrait of Eileen Collins and SpaceX's DSCOVR launch photograph, distributed by [scikit-image](https://github.com/scikit-image/scikit-image/blob/v0.24.0/skimage/data/_fetchers.py).
